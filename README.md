# Henry-Samuel.github.io

Portfolio site for Henry Samuel.

## About

A minimal static portfolio showcasing selected projects, technical skills, and contact information. Built with plain HTML/CSS and hosted via GitHub Pages.

## Sections

- About
- Featured Projects
- Tech Stack
- Contact

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

## Deployment

This repository is configured for GitHub Pages. Pushes to the default branch are published automatically if Pages is enabled in the repository settings.

## Customization

- Update the project cards, skill tags, and contact links in `index.html`
- Replace the contact URLs with real destinations as needed
- Tweak colors in the CSS `:root` variables at the top of the file
